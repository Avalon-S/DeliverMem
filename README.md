# Retrieved but Not Delivered: Multimodal Memory Delivery for Long-Term Agents

[![arXiv](https://img.shields.io/badge/arXiv-2609.32590-b31b1b.svg)](https://arxiv.org/abs/2609.32590)
[![Project page](https://img.shields.io/badge/Project-Page-c7000b.svg)](https://avalon-s.github.io/DeliverMem/)

Between retrieving a memory and answering from it sits a stage that multimodal memory
evaluations do not isolate: what of the retrieved memory reaches the model, and in what form.
We call it delivery. With the retrieved messages held fixed on MemLens, delivering the
original pixels instead of withholding them raises accuracy by 13.87 points, while making
retrieval perfect adds 2.31. DeliverMem makes three delivery decisions explicit, trains
nothing, and one fixed configuration leads both benchmarks we test (MemLens and DMV-Bench).
